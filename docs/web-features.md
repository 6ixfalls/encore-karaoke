# Upstream feature migration

Presentation is adapted from Encore upstream `c18df440fc8648fe24d7adf0b312df71205cce58` (“new intro card”). The hosted implementation uses TypeScript for the new components, retained canvas lyric renderer, Korean romanization and audio worklets. Existing browser transport/player code remains JavaScript. Shared theme CSS and startup, fanfare and score narration assets retain their upstream form and attribution.

- **Startup:** photosensitivity notice, テレビ character reveal, startup sound, and tile transition. Skip with the on-screen button, Enter, Space or Escape. Reduced-motion settings suppress animation. Playback ownership still gates sounds.
- **Song intro:** upstream title/artist/credits layout and optional BPM/key badges, shown for 2.9 seconds before playback. Missing YouTube BPM, key or composer/lyricist metadata is omitted. No guessed values are displayed.
- **Results:** upstream 3.8-second score animation, score ranks, 67-particle confetti, MIDI fanfares, WAV narration, and top-five room scores. The result break lasts up to 14 seconds and can be skipped immediately. Performances without a valid score show “Song complete”; skipped/failed tracks do not invent results. MIDI fanfares use the retained portable browser synthesizer rather than the removed desktop SoundFont engine.
- **Vocal entry and breaks:** three-second countdowns for known lyric gaps and upstream interlude styling/tips for breaks of at least eight seconds. These follow media time and therefore freeze when paused and reset on seek. Missing timed cues produce no speculative countdown.
- **Lyrics:** upstream canvas layout, outlines, alternating rows, fades and color palettes, with selectable font, scale, line spacing, bottom margin, case, alignment and ±5-second offset. Japanese uses the same Kuroshiro/Kuromoji analyzer on the server, with bounded concurrent conversion and cache. Korean uses a TypeScript port of upstream’s Aromanize Revised Romanization rules. Dictionaries, fonts and sounds are local. Exact-video captions still have line-level timing; this migration does not invent syllable timestamps.
- **Audio:** room-scoped ±12-semitone key control independent of tempo; upstream pitch-shift worklet; seven-band and parametric EQ, compressor, echo, noise gate, and vocal gain. Local monitoring is opt-in. Phone vocals and processed recording have independent routes so disabling local monitoring does not mute phones or recordings. Target pitch and scoring account for transposition. Speaker and capture buses retain the audio-thread lease cutoff.

TV preferences are validated and stored in browser local storage. They are not account data and do not make server rooms persistent. Use the TV settings reset button to restore defaults. Local/phone microphone permissions remain explicit browser actions. No camera or microphone is enabled by the intro, lyrics or scoring guide.

The web build dependency graph was used to remove unused desktop boot/load managers, service/IPC wrappers, native configuration, separate remote app, games, OBS/streaming windows, library managers, desktop packaging resources, unused libraries and assets. Standby video, required fonts/icons, audio cues, active web code and license notices are retained. `build-server.mjs` builds only the hosted entrypoint and the TypeScript audio worklets.
